## Concepts I Learned
### Automation
A system that performs tasks automatically without human intervention.

### Trigger
The event that starts the automation.

### Action
The task performed after the trigger occurs.

### API
A structure that allows systems to communicate with each other.

### JSON
A data format used for transferring information between systems.

### Webhook
A system that automatically sends data when an event happens.

### Scenario
The complete automation workflow inside Make.com.
